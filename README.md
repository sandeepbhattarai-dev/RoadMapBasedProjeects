# Instructions to understand the project
- This is the project completed based on following the RoadMap.
Contains a dev branch and a main branch. The dev branch is used for development and testing, while the main branch is used for production-ready code.

- Any new features and bug is created in new branches from the dev branch. Once the feature or bug fix is complete, it is merged back into the dev branch for further testing. After thorough testing, the changes are then merged into the main branch for deployment.

- For this project the master acts as the minimum code and dev is a working branch. The dev branch is used to create new branches for features and bug fixes, the new branches naming is prefixed by 'week-X'. Once the feature or bug fix is complete, it is merged back into the dev branch after signal from the team. After thorough testing, the changes are then merged into the main branch for deployment.
