# My Roadmap
## Month 1: Foundation and Basics
## week-1 : Introduction to .NET Core and ASP.NET Core
- [ ] Tasks:
  - Install .NET Core SDK and Visual Studio.
  - Understand the .NET ecosystem and .NET Core vs .NET Framework.
  - Create a new ASP.NET Core MVC project.
  - Learn the structure of an ASP.NET Core project: `Program.cs`, `Startup.cs`, `appsettings.json`.
- **Project Output:** 
    - Create a "Hello World" ASP.NET Core MVC web application and deploy it locally.


## week-2: Understanding Project Structure and Configuration
- [ ] Tasks:
  - Deep dive into `Program.cs` and `Startup.cs`.
  - Explore `appsettings.json` and environment-specific settings.
  - Configure basic settings in `appsettings.json`.
- **Project Output:**
    - Modify `appsettings.json` to include a custom configuration section and read these values in a controller action.

## Week 3: Controllers, Actions, and Routing
- [ ] Tasks:
  - Understand the role of controllers and actions.
  - Learn about routing and configure custom routes.
  - Pass data from controllers to views. 
- **Project Output:**
    - Create a controller that handles basic CRUD operations and configure routing for these actions.

## Week 4: Views and Razor Syntax and Layouts
- [ ] Tasks:
  - Understand Razor syntax and create views.
  - Use layouts and partial views for reusable components.
  - Bind data to views using view models.
   - Bootstrap Framework
- **Project Output:**
  - Develop a simple web application that (displays a list of items) -output and detailed views using Razor (Presentation).
   - Develop dynamic cards using bootstrap cards, grids etc.

# Month 2: Intermediate Level Development

## Week 5: Models and Data Binding
- [ ] Tasks : 
  - Create models to represent data.
  - Bind data between models, views, and controllers.
  - Learn about model binding and model validation.
- **Project Output:**
  - Create a model for a product and develop a form to create and edit products, including validation.

## Week 6: Entity Framework Core
- [ ] Tasks : 
  - Introduction to Entity Framework Core (EF Core).
  - Setup EF Core in an ASP.NET Core project.
  - Perform CRUD operations using EF Core.
- **Project Output:**
  - Implement EF Core to interact with a database for product management.

## Week 7: Dependency Injection
- [ ] Tasks : 
  - Understand Dependency Injection (DI) in ASP.NET Core.
  - Register services in `Startup.cs` and Project.cs.
  - Use DI in controllers and services.
- **Project Output:**
  - Refactor the application to use DI for data access and other services.

## Week 8: Authentication and Authorization
- [ ] Tasks : 
  - Introduction to authentication and authorization.
  - Implement authentication using ASP.NET Core Identity.
  - Secure actions and views using authorization.
  - Cookie based vs Token Based Authorization
- **Project Output:**
  - Add user registration, login, and role-based access control to the application.
